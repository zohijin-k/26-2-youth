# Design

Extend ProgramPosting and its existing API/UI rather than introducing a second registry. Prefer additive tables and JSON metadata for backward compatibility. Form layouts retain existing coordinate schema with confidence/review metadata. Generic applications must use confirmed snapshots, safe public projections and existing document assessment boundaries. Officer review detail files are immutable; generic rows must not open incompatible score sheets.

## Safety
No real applicant documents or production storage inspection. Pre-existing task.json and root logo excluded. Scan staged changes before every commit.
