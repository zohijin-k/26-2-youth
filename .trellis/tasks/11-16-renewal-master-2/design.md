# Design

Central ASGI guards enforce application ownership and signed officer sessions before routing. Public blank-form assets are explicit exceptions. Additive review/draft tables preserve existing data. New generic detail imports the unchanged DocumentViewer. Notice extraction produces evidence-backed review candidates and connects only supported rule adapters. Managed publishing validates reviewed metadata as well as existing form layout hashes. Applicant snapshots expose an allowlisted projection. Optional text providers receive only notice text and supplemental public text.
