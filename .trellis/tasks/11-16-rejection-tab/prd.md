# 신청 목록 반려 탭

사용자 요청 2026-11-16: 반려 페이지를 어디서 보는지 → 처음에 "사업 정보 옆 버튼"을 제안했다가 "처리 완료 옆 탭"으로 위치를 바꿈.

- 신청 목록 구분 탭에 `반려` 추가(처리 완료 오른쪽). 처리 완료 중 반려한 건만, 신청자에게 보낸 안내와 반려일을 함께 보여 준다. 신청번호를 누르면 심사 화면.
- 취업지원패키지 목록과 사업별 목록 모두.

확인: 백엔드 전체, 프론트 tsc/oxlint/단위/빌드, Playwright(e2e.mjs, 11-16-officer-sort-reject/e2e_backend.py 임시 DB) 5/5.
